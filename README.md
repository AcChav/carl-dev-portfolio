# Developer Portfolio

Personal portfolio web application showcasing full-stack projects, architecture designs, technical skills, and background.

---

## Tech Stack

* **Frontend:** React, Tailwind CSS, JavaScript (ES6+)
* **Full-Stack & Backend Proficiencies:** Node.js, Express, PostgreSQL, Firebase, EJS
* **Other Tools & Languages:** C++, jQuery, Git

---

## Key Features

* **Instant Search & Tech Filter:** Dynamically query projects by keywords or specific technologies (e.g., React, PostgreSQL).
* **Architecture Tagging:** Project categorization badges (Full-Stack, Frontend, Backend) with direct GitHub repository and live demo links[cite: 7].
* **Paginated Showcase:** Multi-page grid navigation keeping layout responsive and performant[cite: 7].
* **Responsive Card Layout:** Modern dark-mode UI displaying quick developer profile info, CV access, and social contact channels[cite: 7].
* **Dynamic Content Engine:** Project listings and descriptions managed decoupled via structured data configurations (`projectsData.js`).
