# Developer Portfolio

A personal portfolio web application showcasing my **full-stack projects, technical skills, architecture designs, and professional background**.

## Live Demo

**[View Portfolio](https://carl-lio.vercel.app/)**

## Tech Stack

* **Frontend:** React, Tailwind CSS, JavaScript (ES6+)
* **Backend & Full-Stack:** Node.js, Express, PostgreSQL, Firebase, EJS
* **Other Tools & Languages:** C++, jQuery, Git

## Key Features

* **Project Search & Filtering** — Search projects by keywords and filter them by technology, such as React or PostgreSQL.
* **Project Categorization** — Projects are organized using architecture and development tags such as Full-Stack, Frontend, and Backend.
* **Project Links** — Each project provides direct links to its GitHub repository and live demo when available.
* **Paginated Showcase** — Projects are displayed through a responsive multi-page grid for easier navigation.
* **Responsive UI** — Dark-themed interface designed to provide a consistent experience across desktop and mobile devices.
* **Developer Profile** — Includes quick access to my background, CV, and social/contact channels.
* **Dynamic Project Data** — Project information is maintained separately through structured configuration data in `projectsData.js`.

## Getting Started

### Prerequisites

* Node.js v18+
* npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/AcChav/<your-portfolio-repo-name>.git
cd <your-portfolio-repo-name>
```

2. Install the dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the local development URL provided by the application.
